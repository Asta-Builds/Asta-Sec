1. Install Root Certificate Authority (CA)

To intercept and decrypt HTTPS traffic, download the ASTA-SEC Root Certificate and trust it in your OS or browser certificate store.

Download asta-ca.crt
  • Windows: Double click asta-ca.crt → Install Certificate → Local Machine → Place in "Trusted Root Certification Authorities".
  • Firefox: Settings → Privacy & Security → Certificates → View Certificates → Import → Select asta-ca.crt → Check Trust this CA to identify websites.
  • Chrome / Edge: Inherits the Windows Trusted Root store configured above.

2. Configure Browser Proxy

Configure your browser or proxy extension (like FoxyProxy) to route traffic through ASTA-SEC:

Proxy IP: 127.0.0.1
Proxy Port: 8080
Protocols: HTTP & HTTPS

Command Line (cURL Testing):

curl -x http://127.0.0.1:8080 --cacert asta-ca.crt https://httpbin.org/get
